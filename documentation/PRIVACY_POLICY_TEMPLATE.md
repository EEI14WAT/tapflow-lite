## Data handled by the app

TapFlow Lite uses Android AccessibilityService to execute user-configured clicks and swipes in other apps. It can use Android MediaProjection to inspect the screen only when the user explicitly starts an image-detection scenario.

This validation edition does not include an advertising SDK, analytics SDK, account system, cloud sync, or developer-operated network service. Scenarios and captured images are stored locally on the device.

## Permissions

The user must explicitly enable the accessibility and overlay capabilities required for automation. Android presents screen-capture consent when an image-detection scenario starts. These capabilities are not used to collect data for the developer.
